# Houdini MCP

An MCP server for SideFX Houdini.

## Installation

Create a virtual environment and install the server:

```sh
python -m venv .venv
.venv/bin/pip install -e .
```

Run it:

```sh
.venv/bin/python -m houdini_mcp
```
