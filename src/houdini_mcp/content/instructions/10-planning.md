# Planning

- Restate the goal in one sentence before multi-step work.
- Inspect first: scene, selection, frame range, existing network, and node errors.
- Plan the whole change before the first edit.
  Prefer one atomic operation over a click-by-click sequence.
- If the request is ambiguous, ask one focused question.
  Do not guess at intent.
- Work coarse to fine.
  Build a draft, show it, then raise quality only with approval.
- Cache expensive stages.
  A cache is a checkpoint, not a deliverable.
- Stop when the goal is met.
  Do not add unrequested polish, nodes, or parameters.
