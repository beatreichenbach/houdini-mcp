# Documentation

Look it up; do not guess.

For a known pipeline, the workflow guide and the live template are the documentation.
Do not re-read node help or re-derive parameters the workflow already specifies.
Use the manual for genuinely unknown behaviour.

## Local first

- `search_help(query)` and `get_help_page(path)` use the installed Houdini manual.
- Read the workflow or shelf page before the node page when learning a setup.
- The local manual is version-exact. If a page is missing, say so.
