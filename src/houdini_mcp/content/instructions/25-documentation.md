# Documentation

Look it up; do not guess.

## Local documentation first

- Use `search_help(query)` and `get_help_page(path)` for the Houdini manual installed with the running version.
- Read the workflow or shelf page before the node page when learning how a setup is normally built.
- The local manual is version-exact and is the authority for Houdini behavior.
- If a page is missing locally, say so; do not invent its contents.

## Web lookup

or current release.
