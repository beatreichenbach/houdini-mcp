# Server boundary

Treat the MCP server as the interface, not as source material.

- Use the server's tools, prompts, resources, and the installed Houdini help.
- Do not read or search the server or plugin source code to answer a Houdini question.
- Do not bypass a missing tool with raw HTTP, Python, HOM, or a direct hwebserver call.
- If a tool is missing, fails, or returns something unexpected, report the exact tool and error.
  Ask for a server change instead of reverse-engineering it.
- Source inspection is allowed only when the user explicitly asks to develop, debug, or review the
  server.
